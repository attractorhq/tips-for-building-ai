# Contributing

Questions, production experience, and focused improvements are welcome.

Use GitHub Discussions for open questions. To propose a tip, open the
“Suggest a tip” issue and explain the concrete situation, the advice, and the
trade-off it helps a team navigate. Advice should be provider-neutral,
practical, and understandable across product disciplines.

Before opening a pull request:

1. Keep the “Advice / Why it matters / Try this / Watch out” structure.
2. Explain why the change improves a real decision or workflow.
3. Run the Markdown, spelling, and link checks used in CI.
4. Update the reading paths or resources only when the change requires it.

Avoid promotional links, unexplained jargon, and claims that depend on a single
tool or model provider.

Follow the [Code of Conduct](CODE_OF_CONDUCT.md). Contributions are accepted
under Apache-2.0.
